# Assets

Drop your real brand assets here and the app will pick them up:

- `logo.svg` — top-right logo (currently a text placeholder `◈ FontMaker` in `src/index.html`)
- `icon.png` / `icon.icns` / `icon.ico` — application icon for packaged builds
- `tool-*.svg` — optional custom tool icons (currently Unicode glyph placeholders)

Until these exist, the UI falls back to lightweight built-in placeholders so the
program is fully usable.
