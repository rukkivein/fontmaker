# FontMaker

A glyph-based **type design studio** — built as a real desktop program (Electron,
the same WebView-style stack Photoshop uses), not just a web page. The workflow is
intentionally **Photoshop-like**, with **Illustrator-style path editing**, and a
dark/light UI with subtle Apple-ish glassmorphism.

Goal: take letter shapes (e.g. randomly generated by an AI project), drop them onto
individual glyphs, refine them, and **export a real OpenType font** — an independent
tool in the spirit of Fontself, but standalone.

---

## Run

```bash
npm install
npm start        # launches the desktop app
npm run dev      # same, with DevTools
```

### Tests

```bash
node test/export.test.js                 # validates real OTF export (backend)
xvfb-run -a npx electron test/smoke.js    # headless boot + interaction smoke test
```

## Architecture

```

  main.js                 window, IPC, dialogs
  menu.js                 native menu  (File / Edit / Window / Help)
  projectIO.js            project save / load (.fontmaker JSON)
  fontExport.js           real OpenType export via opentype.js
  fileWatcher.js          watches imported .ai/.svg → "source changed?" prompt
  preload.js              safe contextBridge API (window.fm)

src/                      renderer (UI + editor)
  index.html  styles/     top bar · control panel · toolbar · boards · test bar
  js/
    store.js              central state + undo/redo + pub/sub
    data.js               alphabets (Latin/Cyrillic/Greek/Arabic/…), grid presets
    project.js            project model, master-compatible point inserts
    geometry.js           bezier math, hit-testing, SVG path build
    viewport.js           world↔screen (pan / zoom / rotate)
    svgimport.js          SVG/AI path parser → editable contours
    glyphboard.js         glyph editor: grid, ghost, masters, point/handle render
    workboard.js          Illustrator-like artboard; drag shapes → glyphs
    chartboard.js         glyph grid (the character map) with live previews
    tools.js              Position · Point · Area · Brush(liquify) · Pin Mesh ·
                          Simplify · Add Shape · Axis(curves)
    layout.js             flexible 3-board split + splitters + master tabs
    controlpanel.js       contextual tool controls + global controls
    menus.js  modals.js  toolbar.js  testbar.js  toast.js
    app.js                bootstrap + action dispatcher + shortcuts
```

### The three boards
- **Glyphboard** — edit one glyph; splits into one pane per open **master**
  (tabs top-right). Other masters can be shown as ghosts; background **font grid**
  is movable in symmetric mode via **Tab**. System-font **ghost** letters guide you.
- **Workboard** — an Illustrator-style artboard for imported SVG/AI vectors.
  Select a shape and **drag it onto a glyph** in the chartboard to assign it.
- **Chartboard** — the flexible character map. Fills the screen when the other
  boards are closed; shrinks to share space when they open.

### Global controls (top-right of control panel)
Ghost on/off · Grids on/off · **Link masters** (mirror edits) · **Variable test**
(animated interpolation between masters) · **Master ghosts** menu.

### Masters & the structural invariant
All master layers of a glyph are kept **structurally identical** (same contour and
point counts, same order) so interpolation and ghosts always work — the model the
Glyphs app / UFO designspace rely on. Therefore **structural edits apply to every
master at once**, while geometric tweaks stay per-master:

- **Add Shape / assign-from-workboard** → written to *all* masters (identical start).
- **Alt-click** the outline (Point or Axis tool) → inserts a point in *all* masters,
  each placed on *its own* curve via a de Casteljau split, so shapes are preserved.
  (Turning a master's V into a W adds the same points to the unseen V too.)
- **Delete** points → removed from *all* masters.
- **Brush** point-densifying and **Simplify** point-removal also propagate, keeping
  counts in lock-step. *Link masters* additionally mirrors geometric moves.

### Export
OTF with a metadata dialog (family, style, designer, version, copyright, license)
and a destination chooser. Contour **winding is normalized on export** (outer CCW,
holes CW) so counters in O, A, e, etc. punch correctly even though the editor draws
with the even-odd rule. TTF/WOFF currently write OpenType-CFF bytes; true `glyf`
TrueType, WOFF wrapping and variable `fvar`/`gvar` are the next steps.

## References studied
- **Glyphr Studio 2** (open source, JS + opentype.js — same stack): confirmed the
  real-time **winding-direction** approach for fills/holes, now implemented here.
- **paper.js `PathItem.Boolean`**: the standard for a real Illustrator-style
  Pathfinder (unite/subtract/intersect) + overlap removal — the planned integration.
- FontForge / UFO designspace: master compatibility & interpolation model.

## Known limitations (honest list)
- Pathfinder (boolean ops) and a path-level Simplify command are not in yet (only a
  Simplify *brush*); overlapping shapes aren't unioned before export.
- TTF/WOFF/variable export are placeholders over OTF-CFF (see above).
- Grid lines highlight in edit mode but aren't draggable yet; per-glyph grid
  overrides aren't stored.
- Accented glyphs are independent outlines (no components); Arabic/Hebrew/Japanese
  are code points only (no shaping / GSUB / GPOS).
- Undo snapshots the whole project per gesture (fine for now, heavy at huge scale).
